STEP 1: CREATE YOUR COMPONENT FOLDER
-------------------------------------
1. Create folder: component_tharsan/
2. Put ALL your project files inside component_tharsan/
   - Your main script (e.g., analysis.py, detector.py, etc.)
   - models/ folder with your trained models
   - requirements.txt (your dependencies)
   - Any other files you need

Structure should look like:
component_tharsan/
├── your_main_script.py
├── models/
│   └── your_model.pt
├── requirements.txt
└── component_service.py  (you'll create this in Step 2)

----------------------------------
Create file: component_tharsan/component_service.py

Copy this code and modify the imports/functions to match YOUR code:

```python

    Returns: {'approved': True/False, 'reason': 'explanation'}
    """
    try:
        data = request.get_json()
        image_path = data.get('image_path')
        issue_type = data.get('issue_type')
        
        # TODO: Call YOUR analysis function
        # Example: result = your_analysis_function(image_path, issue_type)
        
        # TODO: Return your result in this format
        return jsonify({
            'approved': True,  # or False based on your logic
            'reason': 'Your explanation here',
            'confidence': 0.95,  # optional
            'details': {}  # optional additional info
        })
        
    except Exception as e:
        return jsonify({
            'approved': False,
            'reason': f'Error: {str(e)}'
        }), 500

@app.route('/health', methods=['GET'])
def health():
    return jsonify({'status': 'healthy', 'component': 'tharsan'})

if __name__ == '__main__':
    print("🚀 Starting Tharsan's Component Service...")
    app.run(host='0.0.0.0', port=5004, debug=True)
```
