================================================================================
KEY CONCEPTS FOR VIVA DEFENSE
================================================================================

1. ENSEMBLE LEARNING
   - Multiple models voting together
   - Reduces individual model errors
   - Weighted voting based on confidence

2. ADAPTIVE THRESHOLDING
   - Different thresholds for different classes
   - Learned from validation data
   - Balances precision and recall

3. MULTI-LAYER VALIDATION
   - Layer 1: ML models (YOLO)
   - Layer 2: Parameter validation (CV algorithms)
   - Layer 3: Context-aware filtering
   - WHY: Catch edge cases, reduce false positives

4. PRIVACY-FIRST DESIGN
   - Human detection runs first
   - Realism checks (icons vs real people)
   - Size filtering (ignore tiny detections)

5. GRACEFUL DEGRADATION
   - System works even if models fail to load
   - Falls back to parameter-based detection
   - Fail-open for technical errors (don't block users)

6. PERFORMANCE OPTIMIZATION
   - Text-only fast path (skip image models)
   - Early rejection (documents, privacy)
   - Conditional model execution

7. GOVERNMENT-GRADE STRICTNESS
   - Strike system for violations
   - Multiple validation layers
   - Detailed logging for auditing

================================================================================
COMMON VIVA QUESTIONS & ANSWERS
================================================================================

Q: Why use 6 models instead of 1?
A: Ensemble learning reduces errors. Each model trained on different data subsets,
   catches different abuse patterns. Voting consensus more reliable than single model.

Q: Why different thresholds for different classes?
A: Weapons are critical threats (lower threshold to catch all).
   Blood has many false positives from red objects (higher threshold).
   Learned optimal thresholds from validation set.

Q: How do you handle false positives?
A: Multi-layer validation:
   1. Realism checks (texture, color complexity)
   2. Context-aware filtering (car interior, normal photos)
   3. Confidence-based filtering (weak detections in safe contexts)

Q: Why check for documents separately?
A: Documents have high edge density, trigger false positives in abuse detection.
   Pre-filtering saves GPU time and improves accuracy.

Q: What if models fail to load?
A: Graceful degradation - fall back to parameter-based detection using
   OpenCV algorithms (edge detection, texture analysis, color analysis).

Q: How do you protect privacy?
A: Detect humans using YOLO, reject images with people.
   Realism checks distinguish real people from icons.
   Size filtering ignores tiny/distant people.

Q: Why adaptive weighting in ensemble?
A: High-confidence predictions more reliable, deserve more influence.
   Formula: 0.70 + (0.05 * confidence) - 0.025
   Ranges from 67.5% to 72.5% weight for main model.

Q: How do you handle text-only submissions?
A: Fast path - skip all image models, only run text analysis.
   Saves ~300ms processing time and GPU resources.
